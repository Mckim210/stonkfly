# 사전등록: 초파리의 학습(도파민 기억)이 거래 성과를 개선하는가

2026-10-21 등록. **테스트 날짜 테이프를 하나도 만들기 전, 테스트 날짜에 어떤 실행도 하기 전**에 커밋한다. 이 실험을 위해 테스트 날짜(2026-10-12 ~ 2026-10-21)의 시장 데이터를 본 적 없다. 실험 코드는 커밋 `f34c0c7`(보상 순서 섞기 대조군, 기억 상태 기록, 요약 스크립트)이다. 절차는 [대조 실험](experiment.md)을 따르고, 이 문서가 남은 선택을 고정한다.

## 질문

결과를 보지 않은 새 기간에서, 학습 켠 초파리가 (a) 학습 끈 초파리, (b) 보상 순서를 섞은 초파리, (c) 같은 제안을 순서만 섞은 무작위 투자자보다 나은가?

## 데이터

| 항목 | 고정한 선택 |
| --- | --- |
| 테스트 날짜 | 2026-10-12 ~ 2026-10-21 (10일) |
| 구간 | 매일 UTC 00:00–03:00 (끝 미포함, 최대 180 관측) |
| 출처 | Coinbase 공개 BTC-USDC 1분봉, half-spread 기본값 0.0001 |
| 테이프 명령 | `python -m stonkfly tape --start 2026-10-DDT00:00Z --end 2026-10-DDT03:00Z --out tapes/2026-10-DD.jsonl` |

제외: 2026-10-01(00:00–02:00 구간은 아래 사전 점검용 파일럿), 2026-10-02 ~ 2026-10-11(이전 [skill-or-luck 실험](preregistration.md)의 테스트 날짜로, 학습 켠 초파리 결과를 이미 봤다).

## 날짜마다 실행

| 실행 | 개수 | 명령 |
| --- | --- | --- |
| learn (기본, 학습 켬) | 1 | `python -m stonkfly run --replay tapes/2026-10-DD.jsonl --out runs/2026-10-DD/learn` |
| frozen (학습 끔) | 1 | `python -m stonkfly run --replay tapes/2026-10-DD.jsonl --frozen --out runs/2026-10-DD/frozen` |
| shuffled (보상 순서 섞음) | 1 | `python -m stonkfly run --replay tapes/2026-10-DD.jsonl --shuffle-reinforcement runs/2026-10-DD/learn --shuffle-seed 1 --out runs/2026-10-DD/shuffled` |
| 무작위 투자자 | 1,000명 (시드 1–1000) | `python -m stonkfly.control batch --match runs/2026-10-DD/learn --seeds 1-1000 --jobs N --out runs/2026-10-DD/random` |

- 모든 실행은 기억 초기화 상태에서 새로 시작한다(새 실행 폴더, 이전 체크포인트 없음). 요약 스크립트가 첫 관측의 신경 시간이 500 ms인지로 확인한다.
- 설정은 모두 STONKFLY 기본값: 자본 $100, 하루 주문 24건, 모의 수수료 0.6%, 관측당 신경 시간 500 ms, 한 번 주문 최대 $10. **모의거래만 하며 `--live`는 절대 쓰지 않는다.**
- 순서: 테이프 생성 → learn과 frozen 동시 실행 → learn이 끝나면 shuffled와 무작위 1,000명 실행 → 요약. 동시에 도는 프로세스는 최대 4개. 모든 프로세스는 `OPENBLAS_NUM_THREADS=1`로 실행한다(코어 과점유 방지). 실행 순서와 동시 실행 수는 결과를 바꾸지 않는다.
- `--out runs/2026-10-DD/random`은 날짜별 폴더를 나누기 위해, `--jobs`는 속도만을 위해 붙였다.
- 날짜마다 `python -m stonkfly.learning day runs/2026-10-DD --json results/learning/2026-10-DD.json`으로 요약해 그날이 끝나면 커밋한다.
- 설정·날짜·시드는 결과를 본 뒤 바꾸지 않는다.

## 주요 결과

수수료를 반영한 모의 손익(마지막 관측 매수호가로 평가, `stonkfly.control.outcome()`의 `pnl`).

## 사전 지정 분석

10일이 모두 끝나면 `python -m stonkfly.learning report results/learning/2026-10-*.json --json results/learning/summary.json --md results/learning/summary.md`로 계산한다.

1. **learn − frozen** 손익 차이의 10일 평균과 95% 신뢰구간(t분포, 자유도 9, 임계값 2.2622; 날짜가 단위), learn이 더 나은 날 수.
2. **learn − shuffled**를 같은 방식으로.
3. learn의 날짜별 단측 p = (1 + 무작위 중 손익 ≥ learn) / 1001, 평균 순위. 순위 = 1 + 손익이 learn 이상인 무작위 수(1 = 1,001명 중 최고, 동점은 learn에 불리하게; 즉 순위 = p × 1001).

## 판정 기준

①과 ②의 신뢰구간이 모두 0보다 위일 때만 "학습이 성과를 개선했다"고 쓴다. 그렇지 않으면 "개선 증거 없음".

## 함께 보고

- 제안(BUY/SELL/HOLD)·체결·거절 수, 기억 변화(`changed_edges`, `mean_efficacy`, `sha256`), 관측당 스파이크 수, 전달된 보상/혐오 신호 수, learn과 처음 달라진 관측.
- learn이 더 나을 경우(① 또는 ②의 10일 평균 차이 > 0) 체결 수 차이로 설명되는지 확인하되 **탐색 분석**으로 표시한다. 방법: 날짜별 손익 차이와 체결 수 차이를 나란히 보고하고, 체결 수가 같은 날만의 평균 손익 차이를 따로 낸다.

## 알려진 한계 (미리 밝힘)

- 기억이 약 1,800초에 걸쳐 사라지도록 설계돼 있어 하루 안의 짧은 학습만 검증한다. (관측당 500 ms × 최대 180 관측 = 하루 최대 90 신경초이므로 하루 안의 감쇠는 약 5%다. 매 실행이 새 뇌로 시작하므로 날짜 사이로 기억이 이어지지 않는다.)
- 하루 24건 한도가 초반에 찰 수 있다. 그러면 뒤쪽 제안은 거절되고, 결과는 주로 초반 타이밍과 보유로 정해진다.
- 3시간 × 10일, 자산 하나(BTC-USDC). 좁은 시장 조건만 본다.
- 보상 신호는 포트폴리오 평가손익의 부호이고, 그 직전 행동이 원인이라는 뜻이 아니다. 고통·쾌락을 모델링하지 않는다.
- 학습 켬 상태에서는 외부 보상 신호가 없어도 내인성 도파민 활동이 기억 규칙을 움직일 수 있다(합성 fixture 점검에서 확인). 그래서 learn과 frozen은 첫 보상 신호 전에도 달라질 수 있다.

## 보고 규칙

- 모든 날짜를 결과와 상관없이 보고한다. 날짜·시드·실행을 빼거나 결과를 바꾸려고 다시 돌리지 않는다.
- 중단된 실행은 같은 명령으로 이어서 하고 그 사실을 기록한다.
- 여러 날을 합친 다른 검정은 탐색 분석으로 표시한다.

1. learn과 frozen 각각 10스텝: 첫 보상 신호 전까지 스파이크(`spike_sha256`)가 같은지, frozen의 `changed_edges`가 0인지, learn은 보상 뒤 기억이 바뀌는지.
